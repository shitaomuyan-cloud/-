# 娱乐助手插件仓库

ElainaBot 娱乐助手插件（基于 [ElainaBot_v2](https://github.com/ElainaCore/ElainaBot_v2) 框架）

</div>

## 🎮 功能

| 分类 | 命令 |
|------|------|
| 积分 | `签到`（每日一次 50~200 随机）、`抽奖`（扣 20 积分，得 5~150）、`我的`、`积分排行` |
| 互动 | `抢劫 @对方`、`同归于尽 @对方`、`购买反甲`、`单身狗 @对方/QQ号`、`马内 @对方/QQ号` |
| 红包 | `发红包 积分 份数 口令`、`抢红包 [口令]`、`红包列表` |
| 消耗 | `禁言 @对方 [分钟]`、`撤回`（引用消息后发送）、`生图 描述` |
| 管理 | `添加积分 @对方 数量` / `删除积分 @对方 数量`（仅管理员） |

## 📦 安装

在 ElainaBot_v2 的 Web 面板「插件市场」中搜索 **娱乐助手** 一键安装，或手动放入 `plugins/娱乐助手/` 后重启框架。

## ⚙️ 数据

- 积分/红包数据按群独立存储于插件 `data/` 目录
- 所有规则数值（签到区间、中奖率、消耗等）可在 Web 管理后台调整
